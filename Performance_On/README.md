# 공연:ON 포트폴리오 사이트

공연 공고를 찾기 어려운 밴드/댄스/보컬 팀을 위해 만든 정적 웹사이트입니다.

## 실행 방법
1. 압축을 풉니다.
2. `index.html`을 브라우저에서 열면 바로 실행됩니다.
3. VS Code에서는 폴더를 열고 Live Server로 실행하면 가장 편합니다.

## 구현 기능
- 공연명, 학교명, 지역 검색
- 모집 분야/지역 필터
- 공연 상세 정보 모달
- 마감 임박 표시 강화: 3일 이하 남은 공고를 카드 테두리/배지/리본으로 강조
- 신청서 작성 및 내 신청 내역 저장
- 같은 공연 중복 신청 방지
- 신청 취소 기능: 모집 마감 후에는 취소 버튼 잠금
- 이메일 주소와 공연 영상 링크 선택 입력 처리
- 공연 등록 및 목록 반영
- 등록 시 신청 조건 입력란 추가
- 등록한 공연 공고 삭제 기능
- 공연 종류에 `지역 대회` 추가
- 포스터 이미지 업로드 미리보기 및 등록 공고에 실제 게시
- 반응형 레이아웃

## 파일 구조
- `index.html`: 페이지 구조
- `css/style.css`: 전체 디자인
- `js/app.js`: 검색, 신청, 취소, 등록, 삭제, 모달, 이미지 저장, 저장 기능
- `assets/logo.svg`: 로고 이미지


## v4 수정 사항
- 내가 등록한 공연 공고는 목록/상세창에서 신청 버튼이 보이지 않도록 수정했습니다.
- 신청서 선택 목록에서도 내가 등록한 공고는 신청할 수 없게 비활성화했습니다.
- 공연 분야 라디오 체크 리스트 클릭 시 체크 표시가 비정상적으로 커지는 문제를 CSS에서 고정 크기로 보정했습니다.


## v5 수정 사항
- 신청서의 공연 분야에서 `기타`를 선택하면 세부 공연 종류를 직접 입력할 수 있게 추가했습니다.
- `기타` 선택 시 세부 입력값을 신청 내역에 함께 표시하도록 수정했습니다.
- 체크 리스트/라디오 버튼 클릭 시 체크 표시나 이미지가 확대되지 않도록 크기 고정을 한 번 더 보강했습니다.

## v6 수정사항

- 공연 등록 시 모집 분야를 체크박스로 변경하여 여러 개를 동시에 선택할 수 있게 수정했습니다.
- 선택한 모집 분야가 목록 카드, 공고 카드, 상세 보기, 검색/필터 기능에 모두 반영되도록 수정했습니다.
- 모집 분야를 하나도 선택하지 않고 등록하려 하면 안내 메시지가 뜨도록 검증을 추가했습니다.
- 사이트 하단에 미디어라운드(주) 회사 정보 footer를 추가했습니다.


## v6 멀티 페이지 버전

이 버전은 v6 기능을 기준으로 HTML 파일을 여러 개로 분리했습니다.

- `index.html` : 공연 목록 메인 페이지
- `notice.html` : 공연 공고 페이지
- `applications.html` : 내 신청 내역 페이지
- `apply.html` : 신청서 작성 페이지
- `register.html` : 공연 등록 페이지

기존 v6 기능인 모집 분야 복수 선택, footer, 검색, 신청/취소, 중복 신청 방지, 공고 삭제, 이미지 업로드 반영 기능은 유지했습니다.
